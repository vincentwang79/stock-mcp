# 市场状态、策略筛选、历史回放与版本治理

状态：local-ready-for-agent

## Problem

短线候选若使用未来数据、临时阈值或覆盖旧版本，就无法复现和评估。

## Solution

使用纯函数从截至目标交易日的规范化历史快照生成市场状态、证据和最多三个候选；
使用逐日 walk-forward 回放比较不可变策略版本；提案必须经显式确认后才能激活。

## User Stories

- 防御市场可以返回零候选，进攻市场也不得超过三个。
- 强势回踩为主策略，放量突破为独立的次策略。
- 每个候选携带版本、证据、确认和失效条件。
- 历史候选始终引用生成它的策略版本。

## Implementation Decisions

- `v0.1-proposed` 只是一组待回放阈值，默认不激活。
- 排除 ST、上市不足 180 天、停牌、低流动性和异常连续涨停。
- 行业强度只贡献结构化分数；新闻仅作为人工检查提示。

## Testing Decisions

- 在输入中加入未来 bar 不得改变目标日输出。
- 对同一快照重复运行必须字节级等价。
- 回放逐日裁剪输入，并比较候选数、状态和结构化证据。

## Out of Scope

收益承诺、黑箱新闻评分、自动选参、自动激活策略。
